# Oreum — план

**Що це:** дешборд для відстеження акцій з AI-коментарем.
**Навіщо:** прокачати AI-assisted development end-to-end + інструмент для себе.
**Домен:** oreum.app

---

## Стек (рішення прийнято)

- **Next.js (App Router)** + **Supabase** — Postgres, auth, cron.
- **Vercel** — хостинг.
- **Lightweight Charts** — графіки.
- **Дані:** Polygon.io на старті. Alpha Vantage як запасний.

Окремий Python-движок — **не в MVP**. Повертаємось до нього, тільки коли
з'явиться навантаження, яке Next.js не тягне.

---

## Правило скоупу

MVP — це те, чим я користуюсь **сам, щодня**. Все інше чекає.
Якщо фіча не потрапляє в жоден мілстоун нижче — вона йде в «Пізніше», а не в код.

Сценарії прогнозу на 3–6 місяців у рік. Мультитаймфрейм.
Публічні сторінки для SEO. Платні підписки. Окремий Python-движок.

## Відкриті питання

- Домен: `oreum.app` зайнятий. Ймовірно `oreum.markets` — підтвердити й купити.
  Проєкт у Vercel досі називається `oreum.app`, перейменувати разом із доменом.
- Polygon: якого тарифу вистачить для одного користувача?
- Cron: Supabase `pg_cron` чи Vercel Cron? Врахувати, що з увімкненою
  Deployment Protection зовнішній `pg_cron` впреться в редірект на SSO —
  потрібен bypass-токен. Vercel Cron ходить всередині й цього не бачить.
- Чи потрібен клієнтський шар для кешу даних, чи вистачить Server Components
  разом із Server Actions?
